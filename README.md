# Scrolly — Live & Glass

無料ブラウザ版。Live／Glassを切り替え、文字・色・形を設定してOBS用HTMLを書き出します。

## 使い方

1. index.htmlを通常のブラウザーで開きます。
2. LiveまたはGlassを選び、文字や配色、バーの形を設定します。
3. HTMLをダウンロードします。
4. OBSのブラウザソースでローカルファイルを有効にし、ダウンロードしたHTMLを選択します。幅と高さはサイトの表示に合わせます。

出力はscrolly-live-overlay.html／scrolly-glass-overlay.html。どちらも単体ファイルで、サイトのJS等を同梱する必要はありません。Googleフォントの読み込みにはインターネット接続が必要です。

## 設定

- アイコン5種（なし含む）、正式名称の8フォント。
- 両方の色欄は共通14色・同順。HEXとカラーピッカーにも対応。
- バーの形はカプセル・角丸の2種類。角丸は8px。
- Glassは6配色を用意。ガラスの濃さ18%・枠線の濃さ30%で固定。色は自由に変更できます。
- LiveとGlassの設定はこのブラウザー内に別々に保存します。別端末・別の公開URLには自動同期しません。
- プレビュー背景と位置は確認用です。出力は透明背景で、OBS上の配置はソース自体を動かします。
- Glassは半透明・光・質感による表現で、他のOBSソースをぼかしません。

無料版はHTMLを書き出す方式です。販売中のDock版はOBS内で編集する別商品です。

## 有料版との違い

有料版Live／Glassは、OBS内のドックで変更を反映できます。無料版は変更のたびにHTMLを再出力し、OBSでファイルを差し替えます。
有料版には28種類のアイコン、0〜100%の角の丸み調整、名前付き配色の複数保存・コピー／貼り付けがあります。有料版Glassではガラスの濃さ・枠線の濃さも調整できます。
LiveとGlassは別売りで、フラット／ガラス調という見た目で選べます。
無料版は5アイコン（なし・音符・マイク・ゲーム・吹き出し）。自由な色指定・8フォント・太さ・サイズ・速度・2種類の形も使えます。
